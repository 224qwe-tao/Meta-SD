SD & ComfyUI 圖片 Metadata 讀取器

上傳 PNG / JPG / WebP 圖片，在瀏覽器本地讀取 Stable Diffusion WebUI、Forge、ComfyUI 常見 metadata。

使用方法
⬆

拖放圖片到這裡

或點擊選擇圖片。資料只會在你的瀏覽器內讀取，不會上傳到伺服器。

讀取結果

可讀取的常見資料

Stable Diffusion WebUI / Forge

常見 PNG metadata key 是 parameters。本工具會拆出 prompt、negative prompt、steps、sampler、seed、model 等資料。

ComfyUI

常見 PNG metadata key 是 prompt 和 workflow。本工具會顯示 workflow JSON，並嘗試整理 node 內的文字 prompt、sampler、checkpoint、LoRA。

JPG / WebP

會嘗試讀取 EXIF、XMP 和可見文字。不同軟件保存方式不同，所以 PNG 最穩定。
